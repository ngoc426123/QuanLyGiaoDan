# Hướng dẫn cài đặt Elecrusion

## Trước khi cài

- Đóng Elecrusion nếu đang mở.
- Nếu đang dùng bản cũ, hãy xuất một file backup và ghi lại mật khẩu backup.
- Cần quyền quản trị viên Windows vì bản cài đặt dùng chung cho máy.

## Cài ứng dụng

1. Mở file `Elecrusion Setup 0.1.0.exe`.
2. Nếu Windows SmartScreen hiện cảnh báo, kiểm tra file nhận từ người phụ trách giáo xứ. Chọn **Thông tin thêm**, kiểm tra tên ứng dụng là Elecrusion, rồi chọn **Vẫn chạy**. Không tiếp tục với file nhận từ nguồn khác. Bản phát hành nội bộ hiện chưa ký số.
3. Chọn thư mục cài đặt nếu cần, rồi chọn Cài đặt.
4. Mở Elecrusion từ Start Menu.

## Đặt và dùng mật khẩu dữ liệu

Lần mở đầu tiên, ứng dụng yêu cầu đặt mật khẩu dữ liệu. Mật khẩu này mã hóa toàn bộ sổ giáo dân trên máy.

- Dùng ít nhất 12 ký tự và lưu ở nơi an toàn.
- Mỗi lần mở ứng dụng, cần nhập đúng mật khẩu này.
- Nếu quên mật khẩu, không thể mở hoặc khôi phục dữ liệu. Người quản lý cần giữ mật khẩu ở nơi chỉ người được giao việc biết.

## Sao lưu và khôi phục

Trong Cài đặt, phần Dữ liệu:

1. Chọn Xuất dữ liệu ra file.
2. Đặt một mật khẩu backup riêng cho file đó và ghi lại cùng với ngày tạo backup.
3. Sao chép file backup sang USB hoặc nơi lưu an toàn khác.

Để khôi phục, chọn Nhập dữ liệu từ file, chọn file backup và nhập **mật khẩu riêng của file đó**. Ứng dụng sẽ cho xem dữ liệu sắp bị thay trước khi tiếp tục, đồng thời tự tạo một bản sao an toàn của dữ liệu hiện có.

Không gửi file backup hoặc mật khẩu qua cùng một kênh liên lạc.

## Cập nhật hoặc gỡ cài đặt

- Ứng dụng không tự cập nhật. Khi người phụ trách giáo xứ gửi bản mới, đóng Elecrusion rồi cài đè file cài đặt mới lên bản cũ. Dữ liệu và mật khẩu dữ liệu vẫn ở lại trong hồ sơ Windows.
- Gỡ cài đặt không xóa dữ liệu giáo xứ. Chỉ xóa ứng dụng; cần xóa dữ liệu thủ công khi thật sự cần và đã có backup đã kiểm tra.
